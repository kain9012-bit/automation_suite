# 학교 위치 지도 시각화 — 바탕 도구와 데이터

## 바탕이 된 도구

| 이름 | 출처 | 가져온 것 |
|---|---|---|
| 전북교육청 학교 위치 지도(HTML) | 사용자 제공 | 기능 구성(시군·학교급·설립 고르기, 학교급별 색, 이름표 겹침 피하기, 명단만 표시, SVG 저장) |

- 코드는 가져오지 않고 이 앱의 HTML 도구 방식으로 새로 만들었다. 원본이 인터넷에서 받던 부품(Leaflet, proj4, SheetJS)과
  배경 지도(OpenStreetMap 타일), 4.9MB 경계 파일은 쓰지 않는다. 인터넷 없이 동작한다.
- 이 도구에서 더한 것: 엑셀처럼 쓰는 학교별 수치 표(여러 열·단위, 범위 붙여넣기), 학교명 표준화(학교명 표준화 도구와 같은 규칙),
  수치 위치(오른쪽·아래 줄)와 괄호, 학교급별 모양·범례, 시군 확대, 행정동 경계, 학교 수 표, 고화질 PNG·투명 저장, 앱 안 그림 복사.

경계 출처 표기(admdongkor LICENSE-DATA 의 문구 그대로):

> 본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를
> 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다.

- 사립유치원은 넣지 않는다. 병설유치원은 본교와 같은 위치에 둔다.
- 교육행정자료의 주소·행정동은 틀린 것이 많아 쓰지 않는다(예: '고'가 '고등학교'로 바뀐 '고등학교산면', '농고등학교길').
- 주소정보누리집에서 찾지 못한 2곳(인후유치원, 아이캔유치원)은 원본 도구의 좌표를 쓴다.
- 위치·주소·행정동은 `scripts/school_data/school_locations.json` 에 두고, 다시 만들 때
  `python scripts/school_data/build_school_data.py <교육행정자료_YYYY-MM-DD.xls> <HangJeongDong_verXXXXXXXX.geojson>` 를 쓴다
  (xlrd·mapshaper 는 개발할 때만 씀). 새 학교는 school_locations.json 에 한 줄을 더한다.

## 도구 파일

- `web/index.html` 화면·지도 그리기·학교·경계 데이터를 한 파일에 둔다(약 400KB). 인터넷에서 받는 부품이 없다.
- 그림 복사: 앱 안에서는 `window.__jbeduCopyImage`(src/lib/htmlToolDownload.ts)로 앱이 클립보드에 "PNG"·CF_DIBV5 를 넣는다.
  브라우저(새 창)에서는 흰 바탕으로 복사한다. PNG·복사는 긴 변 약 3,600px 로 그린다.
