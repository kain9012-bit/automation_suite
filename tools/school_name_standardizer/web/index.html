🏫 학교명 표준화 도구(v1.3)
엑셀 파일을 업로드하면 학교명을 자동으로 표준학교명으로 맞춰줍니다. (2026.3.1.기준 신설학교 및 교명 변경 반영)

1. 대상 데이터 파일 업로드

학교명이 들어있는 엑셀 파일을 업로드한 뒤 헤더 행, 학교명 열, (있다면) 지역(행정구) 열을 선택하고 매칭을 실행하세요.

내장된 표준학교명 정보를 불러오는 중입니다...

예: 전주시 / 익산시 / 군산시 / 고창군 등. 이 값을 이용해 복수 후보 중 같은 지역의 학교를 우선 매칭합니다.

아직 대상 데이터가 로딩되지 않았습니다.

2. 매칭 결과

자동으로 매칭된 행은 자동 매칭으로 표시되며, 모호하거나 찾지 못한 행은 검토 필요로 표시됩니다.

※ "검토 필요"로 표시된 행은 결과 파일에서 필터링하여 사람이 직접 확인한 뒤 수정하는 것을 권장합니다.

3. 추가로 붙일 표준학교명 정보 (선택)

매칭된 표준학교명을 기준으로, 아래에서 선택한 항목(예: 설립구분, 학교급, 교육지원청 등)을 결과 엑셀에 함께 추가할 수 있습니다. 선택한 항목은 결과 파일에서 표준학교명 오른쪽에 열로 붙습니다.

※ 아무 항목도 선택하지 않으면 표준학교명 열만 추가됩니다.

후보 중 수동 선택

행 · 원본:

복수 후보가 있는 행은 이 창에서 한 학교를 선택하여 수동 확정할 수 있습니다.

학교명 표준화 도구 사용 가이드

이 도구는 자유롭게 입력된 학교명을 교육청 기준의 표준 학교명으로 정리하고, 표준학교명 데이터베이스에 있는 부가 정보를 함께 붙여 주는 도구입니다.

  1. 대상 데이터 파일 업로드
    - “대상 데이터 엑셀 선택 (.xlsx, .xls)” 버튼을 눌러 학교명이 포함된 엑셀 파일을 업로드합니다.
    - 시트를 선택한 뒤, 헤더 행과 학교명 열, (있다면) 지역(행정구) 열을 지정합니다.
    - 표준학교명은 전북교육청 표준학교명 목록(내장 데이터베이스)과 자동으로 비교됩니다.
  2. 매칭 결과 확인 및 수동 확정
    - “매칭 실행” 버튼을 누르면, 각 행에 대해 원본 학교명과 표준학교명이 매칭됩니다.
    - 자동으로 확실히 매칭된 행은 자동 매칭, 애매하거나 후보가 여러 개인 행은 검토 필요로 표시됩니다.
    - “검토 필요” 행 옆의 버튼을 눌러 후보 목록에서 직접 표준학교명을 선택(수동 확정)할 수 있습니다.
  3. 추가로 붙일 표준학교명 정보 선택 (선택)
    - 3번 카드에서 설립구분, 학교급, 교육지원청 등 표준학교명 데이터베이스에 들어 있는 항목을 체크할 수 있습니다.
    - 기본값은 모든 항목이 체크 해제 상태이며, 필요한 항목만 골라서 선택합니다.
    - 선택한 항목은 엑셀로 내보낼 때 표준학교명 열의 오른쪽에 새 열로 함께 추가됩니다.
  4. 엑셀로 결과 다운로드
    - 매칭 결과와 추가 항목 선택을 마쳤다면, “엑셀로 결과 다운로드” 버튼을 눌러 결과 파일을 저장합니다.
    - 2번(매칭 결과) 카드와 3번(추가 정보) 카드에 있는 다운로드 버튼은 모두 동일하게 동작합니다.
    - 파일명 예시: 원본파일명_학교명표준화.xlsx 형식으로 저장되며,
    기존 데이터에 표준학교명 열과 선택한 추가 정보 열이 오른쪽에 붙어서 저장됩니다.

Tip. 학교명이 지나치게 축약되어 있거나 별칭으로만 적혀 있는 경우에는 자동 매칭이 어려울 수 있습니다. 이런 값들은 먼저 어느 정도 정리한 뒤 표준화를 수행하면 정확도가 올라갑니다.
