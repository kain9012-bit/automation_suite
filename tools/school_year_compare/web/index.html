사용가이드

이 도구는 연도별 학교 데이터를 학교명 기준으로 취합하여, 연도별 값이 나란히 비교되도록 엑셀을 생성합니다. (로컬 처리)

1) 사용 전 준비(중요)

  • 본 도구는 학교코드가 아닌 ‘학교명’으로 매칭합니다.
  • 학교명이 조금이라도 다르면(띄어쓰기/약칭/오탈자/부설 표기 등) 다른 학교로 인식될 수 있습니다.
  • 가능하면 먼저 표준 학교명으로 정리(표준화)한 뒤 사용하면 정확도가 크게 올라갑니다.
    예: “효천초”, “전주효천초” → "전주효천초등학교" 표준학교명으로 통일

2) 모드 안내

  • 모드 A(여러 파일): 연도별 파일을 여러 개 올려 비교 취합
  • 모드 B(한 파일·시트 비교): 한 파일 안의 여러 시트를 연도별 자료로 보고 비교 취합
    시트명(또는 파일명)에 2024 같은 연도가 있으면 자동 인식되며, 필요 시 연도 칸에서 수정할 수 있습니다.

3) 사용 절차

  1. 모드를 선택하고, 파일(또는 단일 파일)을 추가합니다.
  2. 각 데이터의 연도 / 시트 / 열 제목 줄 / 학교명 열이 맞는지 확인합니다.
  3. 고정 항목 / 비교 항목을 체크합니다.
  4. [실행(취합)]을 눌러 결과 엑셀(.xlsx)을 다운로드합니다.

4) 항목 선택 규칙

  • 고정 항목(1번만 생성): 학교급/설립/지역처럼 연도와 무관하게 1개만 있으면 되는 항목
    값은 최신 연도 값 우선, 최신이 비어있으면 다른 연도 값으로 보충합니다.
  • 비교 항목(연도별 열 생성): 실적치처럼 연도별로 비교할 항목
    결과 열 이름: 항목명_연도 (예: 만족도_2024, 만족도_2025)
  • 어떤 항목이 특정 연도에만 존재하면 그 연도 열만 생성됩니다(불필요한 빈 열 생성 방지).

5) 유의사항

  • 동일 학교가 여러 번 나오면 마지막 행 값이 사용될 수 있습니다.
  • 열 제목에 숨은 공백(NBSP 등)이 있어도 자동 정규화하여 인식합니다.
  • 본 도구는 서버 업로드 없이 브라우저(로컬)에서만 처리됩니다.
