📮 K-에듀파인 개인수신그룹 일괄등록 도구(v1.2)
기관명(학교명 포함)을 붙여넣으면, 에듀파인 개인수신그룹 일괄등록 엑셀을 자동으로 채워줍니다. (2026.3.10. 기준)

1. 붙여넣기(기관명 목록)

엑셀/한글 표에서 기관명이 들어있는 열을 복사 → 아래 칸에 붙여넣기 하세요. (여러 열을 붙여넣어도 됩니다)

팁: 한글 표를 복사하면 탭(\t)으로 구분되어 들어옵니다.

아직 입력이 없습니다.

2. 미리보기(일괄등록 양식)

자동으로 찾은 행은 자동 매칭으로 표시되고, 모호하거나 찾지 못한 행은 검토 필요로 표시됩니다.
미리보기 표에서 직접 수정한 뒤 엑셀로 다운로드하세요.

입력 행 수 0
자동 매칭 0
검토 필요 0
# 수신그룹명 원본 기관명
(수정 가능)		 수신기관명 수신기관코드 수신기관구분 수신그룹유형 상태 수동 선택

※ 다운로드되는 엑셀에는 아래 항목만 채워지고, 나머지(수신그룹기호/사용자ID/사용자명)는 공란(공백) 처리됩니다.

후보 중 수동 선택

행 · 원본:

복수 후보가 있는 행은 이 창에서 한 기관을 선택해 수동 확정할 수 있습니다.

개인수신그룹 일괄등록 도구 사용 가이드

이 도구는 기관명(학교명 포함)을 기준으로, 에듀파인 개인수신그룹 '일괄등록 엑셀'을 자동으로 만들어 주는 도구입니다.

  1. 수신그룹명 입력
    - 상단의 “수신그룹명(공통)”에 그룹명을 입력합니다. (예: 2026 학사운영 협조 학교)
    - 모든 행에 동일하게 적용되며, 필요하면 결과 표에서 행별 수정할 수 있습니다.
  2. 기관명 붙여넣기
    - 엑셀/한글 표에서 기관명이 있는 열을 복사해 “기관명 목록 붙여넣기” 칸에 붙여넣습니다.
  3. 기관명 매칭 실행
    - “기관명 매칭 실행” 버튼을 누르면 수신기관명/코드/구분이 자동 채워집니다.
  4. 검토 필요 행 처리
    - 빨간 검토 필요는 표에서 직접 수정하거나 “후보 선택”으로 확정합니다.
  5. 엑셀 다운로드
    - “엑셀로 다운로드(일괄등록 양식)”을 눌러 .xlsx 파일을 저장합니다.

※ 중복 제거(수신기관코드 기준): 같은 기관이 반복되면 1개만 남깁니다(정규화 기준).
※ 수신그룹유형 기본값은 02(문서)입니다.
