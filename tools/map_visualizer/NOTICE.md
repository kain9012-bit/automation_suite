# 지역별 수치 지도 시각화 — 참고한 도구와 지도 데이터

## 참고한 도구

| 이름 | 출처 | 라이선스 | 가져온 것 |
|---|---|---|---|
| PenTong(펜통) '부산 블록맵' | 부산광역시교육청 AI·데이터연구팀 | AGPL-3.0 | 기능 구성만 참고(지도 모양 4단계, 지역별 글자 크기·위치 이동·강조, 붙여넣기, 지도 복사) |

- 코드는 가져오지 않고 이 앱의 HTML 도구 방식으로 새로 만들었다. 펜통이 인터넷에서 받던 부품(D3, html2canvas, Tailwind)과
  지도 파일(2013년 경계)도 쓰지 않는다.
- 이 도구에서 더한 것: 수치에 따라 색 칠하기(작은 값·큰 값 색, 범례), 수치 칸에 엑셀 붙여넣기, 수치 단위,
  상세 설정 접기, 투명 PNG 저장, 앱 안 그림 복사(Rust `copy_tool_image`), 2026년 경계.

출처 표기(admdongkor LICENSE-DATA 의 문구 그대로):

> 본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를

- 행정동을 합쳐 전북 14개 시·군(전주시 완산구·덕진구는 전주시로)과 전국 16개 시·도(전남광주통합특별시 반영)를 만들고,
  보고서용 크기로 단순화해 `web/index.html` 안에 넣었다(약 70KB).
- 다시 만들 때: `python scripts/map_data/build_map_data.py <HangJeongDong_verXXXXXXXX.geojson>`
  (mapshaper 를 npx 로 씀. 경계 날짜가 바뀌면 화면 아래 출처 문구와 이 문서의 날짜도 고친다.)

## 도구 파일

- `web/index.html` 화면·지도 그리기·지도 데이터를 한 파일에 둔다. 인터넷에서 받는 부품이 없다.
- 섬 판정: 가장 큰 땅이 아니면서 다른 지역과 맞닿은 점이 없는 조각만 섬으로 본다('작은 섬' 끄기).
  그래서 완주군 이서면처럼 떨어진 땅은 섬으로 빠지지 않는다.
- 그림 복사: 앱 안에서는 `window.__jbeduCopyImage`(src/lib/htmlToolDownload.ts)로 앱이 클립보드에 "PNG"·CF_DIBV5 를 넣는다.
  투명한 곳은 색을 흰색으로 채워 두어, 투명을 모르는 프로그램에서는 흰 바탕으로 붙는다.
  브라우저(새 창)에서는 클립보드가 투명을 담지 못해 한글에서 검게 붙으므로 흰 바탕으로 복사한다.
- PNG 저장·그림 복사는 화면 크기와 상관없이 긴 변 약 3,600px(화면의 3~6배)로 그린다.
