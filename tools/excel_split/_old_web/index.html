엑셀 분할 도구 사용 가이드

이 도구는 하나의 엑셀 파일을 조건에 따라 여러 개로 자동 분할해 주는 도구입니다.

  1. 엑셀 파일 선택
    - 왼쪽 패널에서 .xlsx, .xls, .csv 파일 한 개를 선택합니다.
    - 파일이 로드되면 첫 번째 시트의 상위 일부가 오른쪽에 미리보기로 표시됩니다.
  2. 분할 모드 선택
    - 행 수 기준 분할: 일정 행 수씩 끊어서 여러 파일로 나눕니다.
    - 특정 열 값별 분할: 선택한 열(예: 학교명, 학년) 값마다 파일을 나눕니다.
    - 시트별 분할: 통합 문서의 각 시트를 개별 파일로 저장합니다.
  3. 옵션 설정
    - 헤더 행 번호, 파일당 최대 행 수, 분할 기준 열, 빈 값 건너뛰기 여부 등을 상황에 맞게 조정합니다.
    - 자동 감지 옵션을 켜 두면 헤더 행 번호를 먼저 추정해 줍니다.
  4. 미리보기 확인
    - 오른쪽 미리보기에서 시트를 바꾸며 구조와 헤더/설명 행을 확인합니다.
    - 상단 배지에서 시트명, 행 수, 열 수를 함께 볼 수 있습니다.
  5. 분할 실행 및 초기화
    - [분할 실행] 버튼을 누르면 선택한 모드와 옵션에 따라 여러 개의 엑셀 파일이 내려받아집니다.
    - [초기화] 버튼으로 파일·옵션·상태를 모두 지우고 처음 상태로 되돌릴 수 있습니다.
