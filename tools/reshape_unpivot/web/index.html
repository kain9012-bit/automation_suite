🔄 형태 변환·언피벗 도구(v1.2)
넓은 가로형 엑셀 표를 분석에 적합한 세로형(UNPIVOT) 구조로 바꾸는 도구입니다.

1. 대상 데이터 파일 업로드

고정 열 선택 필수

엑셀 파일을 불러오면 선택 가능한 열 목록이 여기에 표시됩니다.

선택한 열은 행마다 그대로 유지되며, 선택하지 않은 열이 세로 방향으로 펼쳐집니다.

2. 결과 미리보기

언피벗 결과 미리보기 (상위 200행)

원본 데이터 일부 미리보기

시트와 헤더 설정이 올바른지 확인할 수 있습니다.

형태 변환·언피벗 도구 사용 가이드

이 도구는 가로로 펼쳐진 엑셀 데이터를 세로 형태(언피벗)로 바꿔, 분석·집계에 쓰기 좋은 구조로 변환해 주는 도구입니다.

  1. 원본 엑셀 파일 불러오기
    - “엑셀 파일 선택” 버튼을 눌러 언피벗할 엑셀 파일을 업로드합니다.
    - 시트를 선택한 뒤, 헤더 행이 맞는지 확인합니다. (열 이름 행)
    - 헤더가 없으면 “헤더 없음”을 선택하고, 모든 행을 데이터로 사용할 수 있습니다.
  2. 고정 열 / 언피벗 대상 열 선택
    - 언피벗 후에도 그대로 남길 열(예: 학번, 이름, 학교명 등)을 고정 열로 선택합니다.
    - 점수, 인원수처럼 가로로 여러 열로 있는 값들은 언피벗 대상 열로 둡니다.
    - 언피벗 실행 시, 고정 열은 그대로 보존되고, 선택된 열들이 항목명 열과 값 열 두 열로 길게 펼쳐집니다.
  3. 언피벗 실행 및 결과 확인
    - “언피벗 실행” 버튼을 누르면, 선택한 설정에 따라 데이터가 변환됩니다.
    - 결과 미리보기 표에서 고정 열, 항목명, 값 구조로 잘 변환되었는지 확인합니다.
    - 값이 없는 셀(빈 칸)은 기본적으로 결과에서 제외됩니다.
  4. 결과 엑셀로 저장
    - “언피벗 결과 엑셀 다운로드” 버튼을 눌러 결과를 저장합니다.
    - 파일명 예시: 원본파일명_unpivot.xlsx 와 같이 저장되도록 설정할 수 있습니다.
    - 저장된 파일은 이후 통계 요약 리포트, 피벗 테이블, 그래프 작성 등에 바로 활용할 수 있습니다.

Tip. 언피벗 전에, 같은 의미의 열이 여러 개 섞여 있거나 열 이름이 모호하다면 먼저 열 이름을 정리해 두는 것이 좋습니다. (예: “1학년 점수”, “2학년 점수”처럼 규칙적인 이름일수록 언피벗 후 해석이 쉬워집니다.)
