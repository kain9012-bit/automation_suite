D 간단 추첨기 모음(v1.0)

교직원이 자주 쓰는 이름·번호 추첨, 팀 나누기, 순서 정하기 기능을 제공합니다.

1. 추첨기 선택 및 입력
필요한 추첨기를 선택한 뒤 명단 또는 숫자를 입력하고 실행하세요.
이름/번호 추첨기
이름 명단 또는 번호 범위를 입력하여 1명 또는 여러 명을 무작위로 추첨합니다.
팀 나누기 추첨기
입력한 명단을 무작위로 섞어 지정한 팀 수만큼 나눕니다.
순서 정하기 추첨기
입력한 명단의 순서를 무작위로 섞어 발표·추첨·진행 순서를 정합니다.
2. 추첨 결과
추첨 결과를 오른쪽에 표시합니다. 필요한 경우 그대로 복사해 사용할 수 있습니다.
이름/번호 추첨기
왼쪽에서 값을 입력한 뒤 추첨을 실행하세요.
※ 이름 명단은 한 줄에 한 명씩 입력하세요.
※ 추첨 인원수는 전체 인원 수를 초과할 수 없습니다.
※ 팀 나누기는 팀별 구성원을 한 줄 형태로 표시합니다.
