📚 엑셀 병합 도구(v1.3)
엑셀 파일을 업로드하면 3가지 모드로 파일을 병합해줍니다.
모드 선택 후, 대상 데이터 파일 업로드
    😊
    여기에 파일을 끌어다 놓으세요
    또는 위의 버튼으로 선택하세요
    모드1 옵션
    이 모드는 병합 없이 파일별 1개 시트를 만들어 한 워크북으로 모읍니다. 원본의 셀 병합/색/폰트/정렬/행열크기를 가능한 한 보존합니다.
    모드3 옵션

    결과 미리보기

    엑셀 병합 도구 사용 가이드

    이 도구는 여러 개의 엑셀 파일 또는 여러 시트를 한 번에 병합하기 위한 도구입니다.

    1. 파일 선택
      - 상단의 파일 선택 영역에서 병합할 엑셀 파일들을 선택합니다.
      - 여러 파일을 한 번에 선택할 수 있으며, 파일 목록에서 선택/해제할 수 있습니다.
    2. 병합 모드 선택
      - 화면 상단/중앙의 옵션에서 병합 방식을 선택합니다.
      - 모드 1 : 여러 파일 또는 시트를 한 개의 시트로 위아래로 이어붙입니다.
      - 모드 2 : 여러 파일의 여러 시트를 하나의 통합 엑셀 파일로 만듭니다.
      - 모드 3 : 파일마다 이름이 같은 시트들끼리 묶어서 병합합니다.
    3. 머리글(헤더) 행 확인
      - 자동으로 추정된 헤더 행 번호를 확인하고, 필요하면 직접 조정합니다.
      - 헤더가 제대로 지정되어야 열 이름이 올바르게 유지됩니다.
    4. 병합 실행 및 미리보기
      - 병합 실행 버튼을 눌러 결과를 생성합니다.
      - 화면 하단의 미리보기 표를 확인하여 병합이 의도대로 되었는지 확인합니다.
    5. 결과 저장
      - “서식 보존 XLSX 다운로드” 버튼을 눌러 병합 결과를 내려받습니다.
      - 파일명 예시: 원본명_병합.xlsx 형식으로 저장됩니다.

    Tip. 서로 다른 구조의 파일을 무리하게 합치면 열 정렬이 틀어질 수 있습니다. 가능하면 열 구조가 같은 파일끼리 병합하는 것을 권장합니다.
