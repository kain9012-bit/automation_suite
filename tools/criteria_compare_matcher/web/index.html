사용가이드

목적
- 기준 데이터와 비교 데이터를 선택한 “매칭 키(1개 이상)”로 비교하여, 기준 데이터에 중복값(O/X) 열을 추가합니다.

사용 절차
1) 기준/비교 파일 업로드
2) 각 파일의 시트 선택 (기본: 첫 번째 시트)
3) 자동으로 잡힌 열 제목이 있는 줄이 맞는지 확인 (필요 시 숫자 수정 후 [적용])
4) 기준/비교에서 매칭 키를 1개 이상 선택 (권장: 2개 이상)
5) [실행] → 기준파일명_매칭표시.xlsx 다운로드

서식 보존
- 기준 데이터(.xlsx)는 ExcelJS로 원본을 불러와 서식을 최대한 유지한 채 열만 추가합니다.
- 새로 추가되는 “중복값” 열은 서식 없이 값(O/X)만 기록됩니다.

오프라인 사용
- 내부망에서도 사용 가능
- 외부 네트워크 접근 없음(인터넷 비연결/차단 환경) → 데이터가 외부로 전송되지 않음
- 로컬에서만 처리되어 개인정보 노출 위험 최소화
