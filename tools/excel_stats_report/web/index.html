1. 대상 데이터 파일 업로드

엑셀 데이터를 업로드한 뒤 시트와 헤더 행, 분석 설정까지 순서대로 선택하세요.

예: 시도명, 교육지원청, 학교급, 학년 등

숫자 열 선택

조건 필터 (선택)

예: 학교급 = 초등학교, 학급수 > 0 등

2. 통계 요약

전체 요약 통계, 그룹별 통계, 그래프를 한 번에 확인하고 결과를 엑셀로 저장할 수 있습니다.

통계 요약 리포트 사용 가이드

이 도구는 엑셀 데이터를 바탕으로 요약 통계와 그룹별 통계를 자동 계산하고, 그래프까지 만들어 주는 통합 통계 리포트 도구입니다.

  1. 파일 및 시트 선택
    - 분석할 엑셀 파일을 업로드한 뒤, 통계를 낼 시트를 선택합니다.
    - 헤더(열 이름)가 있는 행 번호가 맞는지 확인합니다.
  2. 기초 통계 요약 확인
    - 숫자형 열에 대해 개수, 결측 비율, 합계, 최소값, 중앙값, 최대값, 평균, 표준편차 등을 자동 계산합니다.
    - “통계 요약 엑셀 다운로드” 버튼을 통해 원본명_통계요약.xlsx 를 저장할 수 있습니다.
  3. 그룹별 통계 설정
    - 학년, 학교, 성별 등 그룹 기준이 될 열을 선택합니다.
    - 통계를 낼 숫자열(예: 점수, 인원수 등)을 한 개 이상 선택합니다.
    - 필요하면 어떤 통계값(합계, 평균, 표준편차 등)을 포함할지 옵션에서 고를 수 있습니다.
  4. 그룹별 통계 결과 활용
    - 그룹별로 계산된 통계를 표 형태로 확인합니다.
    - “그룹별 통계 엑셀 다운로드” 버튼으로 원본명_그룹통계.xlsx 파일을 저장합니다.
    - 필터나 정렬을 활용해 특정 그룹만 골라서 볼 수도 있습니다.
  5. 그룹별 그래프 만들기
    - 그래프로 보고 싶은 숫자열과 그룹 기준을 선택합니다.
    - 그래프 종류(막대, 선, 원형, 도넛)와 값 방식(합계, 최소값, 중앙값, 최대값, 평균, 표준편차, 비율)을 선택합니다.
    - 우측의 그룹 체크박스를 통해 포함할 그룹을 선택하거나, “모두” 버튼으로 전체 선택/해제를 할 수 있습니다.
    - 완성된 그래프는 “이미지로 다운로드” 버튼으로 원본명_그룹그래프.png 형태로 저장됩니다.

Tip. 분석 목적에 따라 “값 방식(합계/평균/비율 등)”과 “그래프 종류”를 바꿔가며 비교해 보세요. 같은 데이터라도 시각화 방식에 따라 전혀 다른 인사이트를 얻을 수 있습니다.
