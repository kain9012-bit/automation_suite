# 한글 용량 압축 — 참고한 코드

| 이름 | 출처 | 라이선스 | 기준 |
|---|---|---|---|
| HWPX 용량 줄이기 도우미 v1.0 | https://gitlab.aigov.go.kr/kimosed/hwpx-size-reduction-assistant | MIT (Copyright (c) 2026) | 커밋 afd7f92 (2026-08-30) |

- 원본은 C#(.NET Framework) 프로그램이다. 코드를 그대로 넣지 않고, 아래 처리 구조를 파이썬으로 옮겼다.
  - 처리 전 검사: 전자서명 항목이 있는 문서는 처리하지 않음, hwpx(ZIP) 구조·mimetype 확인
  - BinData 안의 jpg·jpeg·png·bmp·gif 만 줄이고 그림 파일 이름·형식은 그대로, 움직이는 GIF 는 그대로
  - 결과를 다시 열어 항목 누락·그림 열림 확인, 결과 이름 '원본이름_용량축소.hwpx'
- 줄이는 방법은 원본과 다르다. '기본 줄이기'는 한글의 [그림] → [줄이기] → [용량 줄이기 설정]
  (잘라낸 그림 영역 지우기, 삽입한 그림 크기에 맞춰 줄이기, 설정한 해상도로 변경하기 150dpi)과 같은 일을 한다.
  그래서 그림을 쓰는 곳의 imgDim·imgClip 을 새 픽셀에 맞게 고친다(보이는 크기·위치는 그대로).
  '파일마다 목표 용량 이하'·'전체 합계를 목표 용량 이하'는 이 앱의 PDF 용량 압축과 같은 방식으로 해상도를 낮춰 가며 맞춘다.
- 이 앱에서 더한 것: 옛 한글(hwp)은 설치된 한글로 임시 hwpx 를 만든 뒤 줄임(`hcz_hancom.py`), 암호가 걸린 문서 거르기,
  표 칸 배경 그림도 칸 크기에 맞춰 줄이기, 같은 이름이 있으면 '(1)' 붙이기(앱의 다른 도구와 같음), 중지, 결과 팝업.

## 이 도구 파일

- `hwp_compress_service.py` 처리 규칙과 앱이 부르는 입구(`compress_files`). 앱 연결은 `bridge/extra_tools.py` 의 `run_hwp_compress`.
- `hcz_hancom.py` 옛 한글(hwp) → hwpx 변환(늦은 바인딩, 보안 모듈, 한글 종료 보장). 다른 도구 코드를 불러 쓰지 않는다.
- 다른 도구와 모듈 이름이 겹치지 않도록 내부 모듈 이름은 `hcz_` 로 시작한다.
- 시험: `tests/regression/test_hwp_compress.py` (저장소 루트에서 실행)
