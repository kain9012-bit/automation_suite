전북 학사일정 데이터 추출기 사용 가이드

탭1(달력 조회)는 학교명을 검색해 해당 학교의 월별 학사일정을 달력으로 확인하는 기능입니다.

탭2(데이터 추출)은 전북 전체 학교를 불러와 지역/학교급/키워드/기간 조건으로 학사일정 데이터를 엑셀(.xlsx)로 추출하는 기능입니다.

  1. 달력 조회(기본 기능)
    - 탭1에서 학교 검색 → 달력으로 보기 → 날짜 클릭으로 상세 확인
  2. 데이터 추출(두 번째 기능)
    - 탭2로 전환하면 전북 학교 목록이 자동으로 불러와집니다(캐시 우선). → 필터(시·군/학교급) → 기간/키워드 설정 → 엑셀로 추출
주의
- 이 도구는 브라우저에서 NEIS OpenAPI를 호출합니다. 네트워크 정책에 따라 외부 호출이 제한되면 동작하지 않을 수 있습니다.

전북 학사일정 데이터 추출 도구(v1.0)
