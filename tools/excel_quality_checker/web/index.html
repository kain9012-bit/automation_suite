🧹 엑셀 데이터 품질 점검 도구(v1.2)
엑셀 파일을 업로드하면 데이터 품질을 자동으로 진단해드립니다.

1. 대상 데이터 파일 업로드

품질을 점검할 엑셀 파일을 업로드한 뒤 시트와 헤더 행을 선택하세요.

2. 품질 진단 결과

파일 요약과 열별 품질 이슈를 한 번에 확인하고, 문제 있는 행과 열을 엑셀로 내보낼 수 있습니다.

    데이터 품질 점검 도구 사용 가이드

    이 도구는 엑셀 데이터의 품질(결측치, 타입 오류 등)을 자동으로 점검하고 리포트를 만들어 줍니다.

    1. 파일 불러오기
      - 품질을 점검할 엑셀 파일을 선택합니다.
      - 여러 시트가 있는 경우, 분석할 시트를 선택할 수 있습니다.
    2. 헤더(열 이름) 행 확인
      - 자동으로 감지된 헤더 행 번호를 확인합니다.
      - 열 이름이 제대로 잡히지 않았다면 행 번호를 조정한 뒤 다시 분석합니다.
    3. 품질 진단 실행
      - “품질 진단” 또는 이에 해당하는 분석 버튼을 눌러 점검을 실행합니다.
      - 각 열에 대해 다음과 같은 정보를 확인할 수 있습니다.
        · 결측값 비율
        · 추정 데이터 타입(숫자/날짜/텍스트)
        · 타입 오류 개수, 날짜 형식 오류 개수 등
    4. 이슈 행/요약 리포트 활용
      - “이슈 행만 엑셀로 내보내기”: 품질 이슈가 있는 행만 따로 저장합니다.
      - “열별 이슈 요약 내보내기”: 열 단위로 품질 상태를 정리한 리포트를 생성합니다.
      - 파일명 예시: 원본명_품질진단.xlsx 으로 저장됩니다.
    5. 결측치 처리용 엑셀 만들기
      - “결측 행만 내보내기”: 결측치가 있는 행만 모은 엑셀을 생성합니다.
      - “결측 행 제거 후 내보내기”: 결측치가 있는 행을 제거한 버전을 만듭니다.
      - 이 파일들을 활용해 후속 정제 작업을 진행할 수 있습니다.

    Tip. 품질 진단 리포트는 데이터 상태를 한눈에 보여주는 요약 보고서입니다. 분석이나 보고서 작성 전에 먼저 품질 진단을 통해 데이터 신뢰도를 확인하세요.
